# Cofy – Frontend

Frontend desarrollado con Vue.js para un sistema de gestión de cafeterías y restaurantes, orientado a la administración de productos, mesas, pedidos y pagos.

La interfaz facilita la operación del establecimiento y la comunicación entre el personal de servicio y el área de cocina.

## Funcionalidades principales

- Interfaz para el registro y administración de productos.
- Administración de mesas y control de disponibilidad.
- Asignación de mesas a clientes.
- Registro de pedidos desde el módulo de meseros.
- Visualización de pedidos en el módulo de cocina.
- Gestión de pagos y comprobantes de pago.

## Tecnologías utilizadas

- **Framework:** Vue.js 2.
- **Navegación:** Vue Router.
- **Gestión del estado:** Vuex.
- **Consumo de API REST:** Axios.
- **Notificaciones:** Toastr.
- **Manejo de fechas:** Moment.js.
- **Impresión de documentos:** Print.js.
- **Componentes de selección:** Vue Select.

## Arquitectura

Este repositorio contiene la interfaz de usuario de Cofy, desarrollada como una aplicación web que consume los servicios expuestos por el backend mediante una API REST.
